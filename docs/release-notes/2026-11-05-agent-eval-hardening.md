# LTing Agent 评测与可靠性加固

## 问题

- Agent 工具数量过多，模型选择成本高。
- 修改行程会重复新建，版本缺少初始快照。
- 回退只恢复正文，节点残留。
- H2 会话清理存在整数溢出。
- 多链接导航可能把文案和目的地配错。
- 缺少工具失败、越权、多会话回归用例。

## 修复

- 收敛为 12 个领域工具入口，用 `action` 承载细分操作。
- 新增 `updateTrip`，写入修改前后版本。
- 版本快照保存 `nodes_json`，回退恢复正文和节点。
- 修正 Session Timeout 单位，`max_inactive` 升级 BIGINT。
- 导航链接按文案实体匹配。
- 评测增加工具失败、跨用户越权、双会话隔离。

## 验证（2026-11-05 重跑）

- 完整 Agent 评测：10/10 自动检查通过。
- 结果文件：`docs/evaluation/lting-eval-complete-final-20261105.json`。
- 越权读取被阻止。
- 两个会话历史隔离。
- 回退后正文和节点恢复。
- 服务运行 75 秒无会话清理 overflow。
- 详细结果：`docs/evaluation/LTing-Agent-Eval-Final-20261105.md`

## 已知限制

- 尚无真人用户验收结果。
- 高德和搜索能力受外部 Key 配额影响。
- 12 个领域工具的深层 action 仍需长期回归。
