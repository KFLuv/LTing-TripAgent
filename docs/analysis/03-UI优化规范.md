# 一、问题诊断（实测数据）

**当前 UI"简陋"的根因不是审美，是「没有系统」—— 所有值都是一次性硬编码。**

| 维度 | 实测 | 问题 |
|---|---|---|
| 硬编码颜色 | **87 处 / 48 种不同颜色** | 只有 8 个 CSS 变量，其余全是字面值 |
| `rgba()` | **38 处 / 32 种** | 每种阴影各写一个值 |
| 字号 | **12 种**（12 / 12.5 / 13 / 13.5 / 14 / 14.5 / 15 / 16 / 18 / 19 / 22 / **5**） | 无字号阶梯；**其中 `5px` 是笔误** |
| `padding` | **27 种 / 30 处** | 几乎没有重复值 |
| `border-radius` | **12 种**（3 / 4 / 8 / 10 / 12 / 13 / 14 / 16 / 18 / 999 / 50% / 变量） | 只有 1 处用了变量 |
| `box-shadow` | **13 种** | 无阴影层级 |
| `transition` | **10 种**（0.18s / 0.2s / 0.28s…） | 无统一动效时长 |
| `line-height` | **9 种**（1 / 1.3 / 1.4 / 1.5 / 1.6 / 1.7 / 1.75 / 1.78 / 1.85） | 无行高阶梯 |

> **同样的元素在不同位置长得不一样，整体就"土"。**
> 这不是靠调几个颜色能解决的 —— 要先把值收敛成系统。

# 二、目标：建立设计令牌（Design Tokens）

## 2.2 全量替换规则（**必须逐条执行**）

**把文件里所有字面值替换为令牌引用：**

| 查什么 | 替换为 |
|---|---|
| `font-size: 12px` / `12.5px` | `font-size: var(--fs-xs)` |
| `font-size: 13px` / `13.5px` | `font-size: var(--fs-sm)` |
| `font-size: 14px` / `14.5px` | `font-size: var(--fs-base)` |
| `font-size: 15px` | `font-size: var(--fs-md)` |
| `font-size: 16px` / `17px` / `18px` | `font-size: var(--fs-lg)` |
| `font-size: 19px` / `20px` / `22px` | `font-size: var(--fs-xl)` 或 `--fs-2xl` |
| **`font-size: 5px`** | 🔴 **直接删除这条规则（笔误）** |
| `border-radius: 3px` / `4px` / `8px` | `var(--r-sm)` |
| `border-radius: 10px` / `12px` / `13px` | `var(--r-md)` |
| `border-radius: 14px` / `16px` / `18px` | `var(--r-lg)` |
| `border-radius: 999px` / `50%`（胶囊） | `var(--r-full)` |
| 所有 `box-shadow` | 按语义选 `var(--sh-1)` ~ `var(--sh-4)`；主按钮用 `var(--sh-brand)` |
| 所有 `transition: ... 0.18s` / `.2s` | `var(--dur-fast)` 或 `var(--dur-base)` |
| 所有 `transition: ... .28s` | `var(--dur-base)` + `var(--ease)` |
| 所有 `padding` / `margin` 数值 | 用 `var(--sp-N)` 组合 |
| `#fff` / `#ffffff` | `var(--surface)` |
| `#22303f` / `#1f2d3d` / `#24405c` | `var(--ink)` |
| `#5b6b7c` / `#5a6b7d` | `var(--ink-soft)` |
| `#8a99a8` / `#94a3b1` | `var(--ink-mute)` |

# 三、组件级优化

## 3.1 消息气泡（当前最影响观感）

**现状:** `.message` 系列样式已有（`:346-516`），但气泡圆角、内边距、头像尺寸不统一。

**要求:**

```css
/* AI 消息 */
.ai-message .message-content {
  background: var(--surface);
  border: 1px solid var(--line);
  border-radius: var(--r-lg) var(--r-lg) var(--r-lg) var(--r-sm);  /* 左下角收角 */
  padding: var(--sp-4) var(--sp-5);
  box-shadow: var(--sh-1);
  font-size: var(--fs-md);
  line-height: var(--lh-loose);
  max-width: min(680px, 78%);
}

/* 用户消息 */
.user-message .message-content {
  background: var(--brand);
  color: #fff;
  border: none;
  border-radius: var(--r-lg) var(--r-lg) var(--r-sm) var(--r-lg);  /* 右下角收角 */
  padding: var(--sp-4) var(--sp-5);
  box-shadow: var(--sh-brand);
  font-size: var(--fs-md);
  line-height: var(--lh-loose);
  max-width: min(640px, 72%);
}
```

**要点:**
- **收角方向要区分 AI / 用户**（AI 收左下、用户收右下）—— 这是"能看出是谁说的"的关键
- **AI 气泡用白底 + 细边框；用户气泡用品牌色实底** —— 对比清晰
- **最大宽度用 `min(px, %)`** —— 宽屏不拉太长，窄屏自动收窄
- 行高统一 `--lh-loose`（消息正文要松，1.8）

**消息头像:**

```css
.message-avatar {
  width: 34px; height: 34px;
  border-radius: var(--r-full);
  flex: 0 0 34px;
}
```

## 3.2 顶部栏

**要求:** 固定高度、毛玻璃、底部分割线。

```css
.chat-header {
  height: var(--header-h);
  padding: 0 var(--sp-6);
  background: rgba(255, 255, 255, .82);
  backdrop-filter: saturate(180%) blur(14px);
  -webkit-backdrop-filter: saturate(180%) blur(14px);
  border-bottom: 1px solid var(--line-soft);
  position: sticky; top: 0; z-index: 100;

```

> `backdrop-filter` 是现代浏览器标准能力，**不是液态玻璃那种 WebGL 方案**，一行 CSS 即可，成本极低。

# 七、禁止事项

| 禁止 | 原因 |
|---|---|
| ❌ 用渐变遮丑 | 渐变不解决间距与层级问题，只会更花 |
| ❌ 加圆角阴影动画到所有元素 | 动效要克制，只给可点击元素 |
| ❌ 引入暗色模式 | 本次不涉及，会成倍增加工作量 |
| ❌ 改字体族 | 现有 `--font-sans` 是全平台字体栈，已合理 |
| ❌ 用 `!important` | 说明选择器结构有问题 |
| ❌ 一次改完所有批次 | 无法定位是哪批引入的问题 |
