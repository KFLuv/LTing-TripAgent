## 三个最值得看的具体发现

### ① 用「前端零调用」量化隐藏功能

审计方式：扫描全部后端接口 + 前端 `fetch` 调用，做交叉比对。

**结果**：后端 57 个接口，前端实际调用 14 个 —— **77% 的能力用户碰不到**。

其中六个功能域是**彻底隐藏**的（前端零调用 + 零提及）：
游记生成 · 工具箱 · 收藏 · 偏好画像 · 行程节点与版本 · 同行人。

### ② 用一个数字解释「AI 为什么只说不做」

| 指标 | 改造前 |
|---|---|
| Agent 注册工具数 | **30 个** |
| `MAX_ROUNDS` | **6** |
| 强制落库规则 | **无** |

一次「行程变更」的完整链路是 6 步（读画像 → 读节点 → 查开放时间 → 算通勤 → 写回 → 出风险清单），
**6 轮刚好够"读一遍"，不够"算一遍 + 写回去"** —— 所以模型倾向于只给文字建议。

### ③ 界面"土"的真实原因是缺少系统

实测：**87 处硬编码颜色 / 48 种不同颜色 / 12 种字号 / 27 种 padding / 13 种阴影**。

已经定义了 8 个 CSS 变量，但只用了少数 —— **有意识，没执行到底**。

治法是唯一的：把值收敛成令牌，而不是凭感觉调色。
