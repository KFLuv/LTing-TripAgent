# LTing 本人验收记录

日期：2026-11-05

## 使用环境

- Windows x64
- 本地 H2 数据库
- 本人 API Key，仅通过本机环境变量注入
- 免安装桌面版

## 已完成的使用流程

1. 打开 LTing 桌面端，确认本地服务健康。
2. 输入广州两天行程，确认行程与节点写入。
3. 修改第二天下午为室内方案，确认修改原行程而非新建重复行程。
4. 查看版本并执行回退，确认正文和预约/风险/备选节点恢复。
5. 未上报定位时询问附近餐厅，确认失败信息明确且不编造。
6. 写入“不吃辣”和“步行耐受低”，确认偏好回显。
7. 新建第二个会话，确认前一会话历史不会串入当前会话。
8. 使用另一个访客身份读取私有行程，确认返回“行程不存在”。
9. 记录门票和预算，确认剩余额度与阈值生效。

## 验收结论

工具失败和越权场景有明确错误状态。
多会话历史和私有行程隔离正常。
